# Inclined GEO 取樣驗證與效能回歸

基準：`main` commit `99b682e08647c71f9e1c0ebf18b33e08b5a7b924`。
量測日期：2026-10-28（Asia/Taipei）。頁面維持獨立 HTML，不需要新增執行階段依賴。

## 取樣範圍與精度

`satEcef(t, ...)` 在每個時間點獨立求解 Kepler 方程，並非用前一點做數值積分。
增加取樣數改善時間網格、取樣極值及可見比例的解析度，不會改變同一時刻的軌道模型或求解器精度。
原本包含起終點的網格 `t = SIDEREAL_DAY * i / (n - 1)`、地平線判斷 `el > 0`、
以及 `visibleCount / n` 定義均保留；可見比例是取樣估計，並非精確的地平線交點時間積分。
起終點重複與交點相位會造成取樣誤差，因此誤差不一定隨點數單調減少。

| 取樣數 | 相鄰時間間隔 | 使用方式 |
| --- | ---: | --- |
| 120 | 724.07 秒 | 保留原有下限 |
| 720 | 119.84 秒 | 保留預設值，繪圖保留所有點 |
| 3,600 | 23.94 秒 | 更細的時間網格 |
| 10,000 | 8.62 秒 | 互動頁面的新上限 |

選擇 10,000 是互動成本與解析度的折衷，並非所有軌道的科學誤差保證。
計算與資料記憶體仍為 O(n)，上限避免單次同步工作、配置量與動畫週期無限制增長。
30 fps、每幀推進一個取樣點的原有互動行為保留，因此較高取樣仍會延長一輪動畫。
如需更高取樣或精確交點時間，應另外設計背景運算與事件定位。

偏心且有地平線交點的案例：觀測者緯度 65°、經度 100°、衛星經度 170°、傾角 45°、
偏心率 0.3、近心點幅角 35°。用原版 100,000 點作為收斂參考（並非精確解）：

| 取樣數 | 可見比例 | 與參考的差（百分點） | 最大仰角 |
| --- | ---: | ---: | ---: |
| 120 | 26.666667% | 0.118667 | 27.260323° |
| 720 | 26.527778% | 0.020222 | 27.285351° |
| 3,600 | 26.555556% | 0.007556 | 27.285874° |
| 10,000 | 26.560000% | 0.012000 | 27.285889° |
| 100,000（參考） | 26.548000% | — | 27.285894° |

## 輸入與繪圖設計

- 數值欄位使用 `valueAsNumber`，空白或無效數字不再被截斷或誤當成可用資料。
  `simulate()` 另外要求有限整數且介於 120–10,000，在配置資料或求解軌道前拒絕無效值。
  例如 `720.5` 不再變成 720；`7.2e2` 正確代表 720。
- HTML 設定 `required`、`min`、`max` 與 `step=1`，搭配欄位說明、`role=alert`、
  `aria-invalid` 及焦點回到取樣欄位。失敗時保留上次成功的資料與統計；成功重算後清除錯誤。
- 經緯度、仰角極值、經度偏移和可見數目在計算迴圈中累計，移除所有大型陣列的引數展開、
  統計用 `map()` 與 `filter()` 暫存陣列。固定兩元素的座標展開仍可安全使用。
- 繪圖採最多 1,440 個均勻選取的基礎點，額外保留六個極值索引、地平線交點兩側與經度換日線兩側。
  因此繪圖點數會稍高於 1,440；最壞情況仍受 10,000 點的計算上限保護。
  三維軌跡座標在重算時快取，避免每幀對全部物理資料重做座標轉換。
- 所有物理資料、統計、目前衛星位置和動畫時間維持完整取樣解析度。
  進度軌跡末端額外插入當前的精確取樣點，並保留天空軌跡的不可見區段。
  高偏心率 `e=0.8`、傾角 60° 的回歸案例另檢查換日線邊界，及降採樣地面軌跡的內插偏差小於 0.5 畫布像素。

## 效能比較

Node v24.22.1 / V8 13.6.233.17-node.58，同一環境執行頁面內的實際腳本。
計算預熱 3 次後取 9 次中位數；繪圖預熱 5 次後取 21 次中位數，取動畫中間幀。
Canvas/DOM 使用測試替身，因此量測包含 JavaScript 座標處理與畫布命令產生，**不包含瀏覽器排版、光柵化與 GPU 成本**。
時間會隨環境、JIT 與負載變動，不能直接解讀為瀏覽器 FPS。

| 項目 | 720 修正前 | 720 修正後 | 10,000 修正前 | 10,000 修正後 |
| --- | ---: | ---: | ---: | ---: |
| 一次計算（ms） | 16.24 | 19.33 | 230.20 | 236.85 |
| 每幀繪圖程式（ms） | 9.80 | 7.96 | 67.79 | 10.54 |
| 每幀 `lineTo` 次數 | 6,041 | 6,041 | 61,721 | 10,385 |
| 保留資料的 V8 heap（KiB） | 108.7 | 227.9 | 1,408.4 | 1,645.5 |
| 繪圖點數 | 720 | 720 | 10,000 | 1,444 |

高取樣繪圖程式約快 6.4 倍，`lineTo` 次數減少約 83%。快取增加一次計算成本與保留記憶體；
10,000 點增加約 237 KiB，換取持續動畫的較低重複工作量。
Heap 以 GC 後保留 10 組資料的平均增量估算，不是尖峰記憶體，也不包含瀏覽器畫布資源。

原版完整 `simulate()` 在 150,000 點時重現 `RangeError: Maximum call stack size exceeded`（Node VM）。
新版相同輸入在運算前顯示範圍錯誤。這不是完整瀏覽器的重現結果。

## 驗證與重跑

從儲存庫根目錄執行，Node 18+，核心回歸與 benchmark 無外部依賴：

```sh
node --test tests/satellite.test.cjs
node --expose-gc tests/satellite.bench.cjs
```

如有完整 Git checkout，可準備原版比較：

```sh
git show 99b682e08647c71f9e1c0ebf18b33e08b5a7b924:Web/satellite.html > /tmp/satellite-before.html
node --expose-gc tests/satellite.bench.cjs /tmp/satellite-before.html
```

11 項核心回歸通過，涵蓋預設值、10,000 點、上下界、空白、NaN、無限值、非整數、
過高取樣、重算恢復、動畫推進、有限經緯度與仰角、全可見／全不可見／部分可見、圓形 GEO 解析性質、
獨立仰角幾何、降採樣極值／地平線／換日線與當前點保留。
`fixtures/satellite-main.json` 記錄原版的統計與代表點；額外的 before/after benchmark
逐一比較 720／10,000 點、圓形／偏心兩種情境的**所有物理資料陣列及統計值，完全相同**。

可選的實際瀏覽器煙霧測試（需另備 Playwright 與 Chromium）：

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/satellite.browser.cjs
```

該測試涵蓋 1280px／390px、原生數值輸入清理、錯誤焦點、恢復、最高取樣、動畫及三個畫布有繪圖。
